# Cryon Intelligence — план реализации

Начало: 25 ноября 2026. Чекбоксы закрываются только после реализации и проверки.

Статус: этапы 1–6 первой поставки реализованы. Инструкция и ограничения:
[cryon-intelligence.md](cryon-intelligence.md). Условные исследования после первой
версии перечислены отдельно и не отмечены как выполненные.

## Цель и границы

Опциональный AI DJ дирижирует доступными рекомендательными каналами: планирует
поиск неизвестной музыки, оценивает результаты и предлагает стратегию следующего
сегмента. Cryon исполняет разрешённые операции и принимает окончательное решение.
Без AI и при его ошибке работает существующий движок. Плеер никогда не ждёт LLM.
Первая поставка — локальный Windows/Android-клиент с BYOK; сервер на 100 пользователей
не входит в текущую работу. Пользовательские ключи остаются в локальном SQLite.

## Точки интеграции и решения

- `internal/recommendations/discovery.go`: двухшаговый поиск открытий уже существует.
- `content.go`: TF-IDF/cosine уже существует; повторно не реализовывать.
- `engine.go`: RelatedTracks финализирует выдачу в defer; нужен осторожный рефакторинг.
- `core/app.go` и `core/api_v1.go`: общий путь необходим для обеих платформ.
- `internal/intelligence`: независимые контракты/валидация; без зависимости от плеера.
- Канал — пара provider + capability, а не обязательно domain.ServiceID: Last.fm/Deezer
  предоставляют музыкальные данные независимо от источника аудио.
- Начальные лимиты — конфигурация Cryon, не полномочия модели. Значения проверяются локально.

  resolvers и запрет YouTube в рекомендациях. Не выполнено полное переписывание

  finalizeRelatedResult с прежним поведением. Старые Wails/related API сохранены,

- any-llm-go v0.9.0 закреплён; OpenAI/совместимые API работают через него, Claude
  через официальный SDK за тем же Director. Причина и исходные лицензии —
  [third-party/NOTICE.md](third-party/NOTICE.md). Нового CGO/DSP/server слоя нет.
- AI выполняется одним bounded worker: отдельные planner/selector, строгий JSON,
  проверка доступных возможностей/бюджетов/ID/ревизий, отмена, timeout, cooldown,
  суточный лимит попыток с сохранением. Ключ недоступен универсальному getter,
  ошибки провайдера обезличены, redirect и автоматические повторы запрещены.
- Метрики: журнал показов/реакций, prepared/fallbacks за запуск, попытки и
  сообщённые API токены за UTC-день. Лайки незнакомых локальному профилю артистов
  считаются как proxy полезных открытий; улучшение качества не заявляется.
- Проверки: `go test ./...`, `go vet ./internal/...`, `git diff --check` — успешно.
  Frontend: 22 файла, 104 теста — успешно; `npm run build` — успешно. Известные
  предупреждения Vite об existing HLS chunk/dynamic imports не блокируют сборку.
- Windows: production `wails build -skipbindings -s` — успешно; EXE запускается
  и отображает экран входа. Форму AI-настроек визуально проверили Playwright на
  desktop и 393×852; скриншоты находятся в frontend/output/playwright/.
  Вход в пользовательскую учётную запись и платный AI-запрос не выполнялись.
- Android: gomobile arm64/AAR и debug APK собраны. APK установлен через `adb install -r`
  с сохранением данных. Из восьми существующих инструментальных тестов шесть
  прошли в общем запуске; два получили таймаут запуска тестовой Activity, затем
  оба прошли отдельно после force-stop. Дополнительный тест AI-радио без WebView
  прошёл: session ID, plan ID, shown/completed и отсутствие перехода на legacy API.
- На окончательном APK отдельно прошёл read-only тест реального встроенного Go
  backend и Android SQLite: /v1/intelligence/config доступен, ключ не возвращается,
  JSON-запросы метрик выполняются. Итого проверены восемь прежних и два новых
  Android-сценария; общий запуск прежних восьми не был полностью зелёным из-за
  описанных таймаутов Activity, успешные отдельные повторы это ограничение не скрывают.
- Реальные OpenAI/DeepSeek/Claude-аккаунты не использовались; HTTP-контракты
  проверены локальным тестовым сервером, включая 401/429/5xx/deadline. Музыкальное
  качество выбранной пользователем модели остаётся предметом реального прослушивания.
- `go test -race` недоступен в текущем Windows-окружении без CGO-компилятора;
  вместо заявления об отсутствии гонок выполнены функциональные проверки отмены,
  ограничений и завершения worker. Тесты не доказывают отсутствие всех гонок.
